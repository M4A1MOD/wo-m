# 智能互动教学平台 Demo 0.4

Demo 0.4 保留了 Demo 0.2 的课程 CRUD 与持久化、Demo 0.3 的九学科差异化课堂，并加入课程知识库与知识图谱、多模态教学内容、AI 教学配图、双导师、多智能体课堂、可绘图 AI 白板、含真实配图与动画转场的 PPTX、完整项目式学习流程、语音、学习记录、可视化学情分析，以及集中管理模型密钥和浏览器语音的系统设置页。

统一离线入口：`outputs/智能互动教学平台-demo0.4.html`。Demo 0.2 和 Demo 0.3 单文件入口继续保留。浏览器中的旧课程会自动迁移并补全 Demo 0.4 数据结构。

## 目录

- `frontend`：Vue 3 + Vite + TypeScript，正式界面与浏览器降级能力。
- `backend`：Spring Boot 3，课程业务与 AI 服务代理。
- `ai-service`：FastAPI，统一模型、资料解析、知识图谱、多模态、语音和报告接口。
- `docs`：功能矩阵、验收记录与开发约定。

## Demo 0.4 验收路径

打开前端后依次体验：生成课堂 → 上传教材/课件 → 编辑知识图谱 → 切换多模态内容 → 体验语音、AI 答疑和绘图白板 → 配置幻灯片配图、对象动画与页面转场 → 在项目式学习工作区完成分组、阶段提交、成果上传和量规评价 → 启动 AI 同学讨论 → 查看记录员笔记与学情分析 → 导出 HTML、JSON、可编辑 PPTX 或 ZIP 完整课堂包。

## AI 绘图白板

进入“互动课堂”，白板支持自由曲线、直线、箭头、矩形、椭圆、文字和公式，可撤销、重做、擦除、切换网格并导出 SVG/PNG。完成 AI 答疑后点击“AI 图解排版”，会把当前 AI 板书内容转换为可继续编辑的图形节点和关系箭头；点击“保存白板”后随课程持久化。

## 幻灯片图片、动画与转场

在“教学内容 → 沉浸文本”生成课程配图后，图片文件会保存到平台资源目录，而不是只记录临时远程 URL。在“PPT 与旁白”中可逐页设置淡入、飞入、出现动画，以及淡化、推进、擦除转场。导出的 PPTX 会将真实图片写入 `ppt/media`，文字仍保持可编辑；空测验等边界数据也会生成可正常打开的文本框结构。

## 项目式学习

进入“教学内容 → 项目式学习”，可创建小组和成员，维护项目阶段、截止日期与状态，上传每阶段成果和填写反馈，并使用可编辑评价量规录入权重与评分。项目分组、阶段提交、成果资源和加权得分随课程保存，并写入 HTML、PPTX 和 ZIP 课堂包中的 `project-progress.json`。

## Windows 一键启动

双击项目根目录的 `一键启动.cmd`。启动器会自动启动 AI 服务、Spring Boot 后端和 Vue 前端，等待三个服务就绪后打开 `http://localhost:5173`。

使用结束后双击 `一键停止.cmd`。运行日志位于 `platform/.runtime`，该目录已加入 Git 忽略列表。若端口 5173、8000 或 8080 被其他程序占用，启动器会停止启动并提示检查端口，不会结束无法确认属于本项目的进程。

## 使用本机 Ollama

项目已支持独立的 `Ollama（本机）` 提供商。当前本机配置位于被 Git 忽略的 `.env`，默认模型为 `qwen3.5:4b`。先确认 Ollama 正在运行，再一键启动平台；前端会默认选择 Ollama，同时保留“本地演示模型”作为备用。

在“系统设置 → AI 模型接口”选择 Ollama，可以刷新并读取 `http://127.0.0.1:11434` 中已经安装的模型，不需要填写 API Key。下载或删除模型仍使用 Ollama 自己的管理方式，平台不会自动下载大模型。

## 使用 AI 教学配图

平台已整合 `project-image-asset-generator` 的火山引擎视觉文生图能力。进入“系统设置 → 教学图片生成”可填写或修改 AccessKey、SecretAccessKey、接口 URL、地域和模型；进入课程工作区后，在“教学内容 → 沉浸文本”的“AI 教学配图”区域为当前场景生成图片。生成结果会显示在沉浸文本、PPT 预览和交互式 HTML 导出中。

Windows 下，图片接口配置保存在 `%APPDATA%\ZhixueTeachingPlatform\image-provider.json`，大模型接口配置保存在同目录的 `llm-providers.json`。这两个文件均位于项目目录之外，复制、压缩或发送整个项目文件夹时不会携带个人密钥。首次启动会自动读取原图片生成器位于 `%APPDATA%\project-image-asset-generator\image-asset-data\config.json` 的配置，并迁移到教学平台用户配置目录。

为避免意外计费，平台启动和健康检查不会自动请求生成图片；只有用户点击“生成本场景配图”时才会调用火山引擎视觉服务。

运行前端构建：`npm run build`。构建并更新独立版：`npm run build:demo`。
