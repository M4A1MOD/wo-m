# 智能互动教学平台 Demo 0.5

Demo 0.5 将原始 Demo 0.4 之后的累计功能归档为新版本，包含课程工作区、选填课程描述、真实 AI 反馈与讨论、结构化导图、互动教材、课程资源库、教学配图、绘图白板、PPTX 图片与动画、项目阶段管理，以及集中管理模型配置和浏览器语音的系统设置页。

当前交付入口为源码与项目根目录的一键启动脚本。本版文档不将历史单文件 HTML 作为 0.5 独立应用；源码、存储键和部分界面/导出仍沿用 0.4 标识，版本兼容范围详见验收记录。

## 目录

- `frontend`：Vue 3 + Vite + TypeScript，正式界面与浏览器降级能力。
- `backend`：Spring Boot 3，课程业务与 AI 服务代理。
- `ai-service`：FastAPI，统一模型、资料解析、知识图谱、多模态、语音和报告接口。
- `docs`：功能矩阵、验收记录与开发约定。

## Demo 0.5 验收路径

打开前端后依次体验：设置模型 → 创建课堂并选填课程描述/上传参考资料 → 在工作台进入课程 → 编辑导图和课程资源 → 阅读教材并提交 AI 反馈 → 体验语音、问答和绘图白板 → 配置幻灯片配图、动画与转场 → 完成项目分组、阶段提交和量规评价 → 启动真实模型讨论 → 查看学习分析 → 导出 HTML、JSON、PPTX 或 ZIP 数据包。ZIP 尚未打包图片和上传附件的二进制文件。

## AI 绘图白板

进入“互动课堂”，白板支持自由曲线、直线、箭头、矩形、椭圆、文字和公式文本，可撤销、重做、擦除、切换网格并导出 SVG/PNG。“AI 图解排版”使用前端规则把当前文字板书转换为图形与箭头，尚非模型直接控制画笔；公式尚未使用 LaTeX 排版。点击“保存白板”后随课程持久化。

## 幻灯片图片、动画与转场

在“教学内容 → 沉浸文本”生成课程配图后，图片文件保存到平台资源目录。在“PPT 与旁白”中可逐页设置淡入、飞入、出现动画，以及淡化、推进、擦除转场。PPTX 导出实现会读取可访问图片并写入 `ppt/media`，保留可编辑文字与动画结构；最终打开和放映效果仍需在目标 Office/WPS 版本验收。

## 项目式学习

进入“教学内容 → 项目式学习”，可创建小组和成员，维护阶段、截止日期与状态，上传成果并填写反馈，编辑评价量规权重及评分。项目数据随课程保存；HTML 展示分组、阶段与量规，PPTX 展示项目摘要与量规，ZIP 的 `project-progress.json` 保存项目结构。当前评分为项目级，阶段提交尚未关联具体小组，ZIP 未包含成果文件二进制。

## Windows 一键启动

预装 Node.js 20+、Python 3.11+、JDK 17+ 后，双击项目根目录的 `一键启动.cmd`。首次运行联网准备依赖，启动器随后启动 AI 服务、Spring Boot 后端和 Vue 前端，等待三个服务就绪后打开 `http://localhost:5173`。

使用结束后双击 `一键停止.cmd`。运行日志位于 `platform/.runtime`，该目录已加入 Git 忽略列表。若端口 5173、8000 或 8080 被其他程序占用，启动器会停止启动并提示检查端口，不会结束无法确认属于本项目的进程。

## 使用本机 Ollama

项目支持 `Ollama（本机）` 提供商。分发的 `.env.example` 中模型名为空、演示模式开启；下载者没有 Ollama 也可以启动平台，使用演示模式或配置云端模型。协同讨论、边读边想和简答题 AI 批改必须连接真实模型。若使用 Ollama，请先自行安装、启动服务并下载模型。

在“系统设置 → AI 模型接口”选择 Ollama，可以刷新并读取 `http://127.0.0.1:11434` 中已经安装的模型，不需要填写 API Key。下载或删除模型仍使用 Ollama 自己的管理方式，平台不会自动下载大模型。

## 使用 AI 教学配图

平台已整合 `project-image-asset-generator` 的火山引擎视觉文生图能力。进入“系统设置 → 教学图片生成”可填写或修改 AccessKey、SecretAccessKey、接口 URL、地域和模型；进入课程工作区后，在“教学内容 → 沉浸文本”的“AI 教学配图”区域为当前场景生成图片。生成结果会显示在沉浸文本、PPT 预览和交互式 HTML 导出中。

Windows 下，图片接口配置保存在 `%APPDATA%\ZhixueTeachingPlatform\image-provider.json`，大模型接口配置保存在同目录的 `llm-providers.json`。两者位于项目目录外，目前为明文 JSON。读取图片配置时可自动迁移当前用户原图片生成器目录中的配置。通过 Git 分发还会忽略 `.env` 等本地文件；普通 ZIP 压缩不遵守 `.gitignore`，因此请分享审核过的源码包，不直接打包开发工作目录。

为避免意外计费，平台启动和健康检查不会自动请求生成图片；只有用户点击“生成本场景配图”时才会调用火山引擎视觉服务。

运行前端构建：`npm run build`。`npm run build:demo` 当前只是同一构建命令的别名，产物为 `frontend/dist`，不会生成内联资源的 0.5 单文件应用。
