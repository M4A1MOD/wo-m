# frontend · Demo 0.4

前端支持 9 个学科的差异化课堂模板，以及知识库/知识图谱、六类多模态内容、双导师、多智能体课堂、语音、白板、学习分析和 HTML/JSON/PPTX/ZIP 导出。

Vue 3 前端目录建议：

- `src/views`：工作台、课堂生成、审核、互动课堂、知识库、结果页。
- `src/components`：跨页面复用组件。
- `src/api`：Axios 请求封装与 DTO 类型。
- `src/stores`：用户、课程和课堂状态。
- `src/router`：路由与权限守卫。
- `src/assets`：样式、图标和本地演示资源。

建议使用 Vue 3、Vite、TypeScript、Pinia、Vue Router、Axios 和 Vitest。
