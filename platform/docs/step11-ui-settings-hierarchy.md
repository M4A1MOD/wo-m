# 第11步：界面可读性、导航层次与 AI 设置

## 本步改动

- 将正文、按钮、表单、说明、标签和课堂内容的字号整体提升，正文主要不低于14px，辅助文字主要不低于12px。
- 左侧导航按“总览、备课、教学、复盘与系统”分组，每个入口增加用途说明；顶部只保留服务状态、当前模型、保存和设置入口。
- 新增“系统设置”页面，集中管理 AI 模型接口和浏览器语音，课堂页面不再重复展示大块语音配置。
- 支持在页面中添加或替换 DeepSeek、通义千问、Kimi、MiniMax 的 API Key 和模型名称。
- 密钥只从浏览器提交到服务端内存，不保存在 localStorage、课程、数据库或接口响应中。AI 服务重启后临时配置自动清除。
- 环境变量配置仍然有效，临时配置优先；页面只能清除本次运行时添加的配置，不能清除服务器环境变量。

## 安全边界

当前项目尚未实现登录和管理员权限，因此运行时配置页面只适合本机开发演示。生产部署前必须增加管理员鉴权，并应使用服务器密钥管理或环境变量，不应开放运行时配置接口给普通用户。

设置接口不主动调用提供商验证密钥，因此保存成功仅表示格式和服务端存储成功。首次生成课堂或答疑时才会实际验证密钥、模型名称和账户权限。

## 验证结果

- FastAPI 检查通过：配置、目录状态、密钥不回传、清除和无效输入验证均正常。
- Java 后端构建通过，并完成真实本地转发联调：前端同路径的配置和清除请求可以经过 Spring Boot 到达 AI 服务。
- Vue 类型检查与生产构建通过，共构建18个模块。
- 使用 Edge 以1440×1000尺寸渲染检查工作台：导航分组、主要标题、课程卡片和操作层次清晰，无明显遮挡或溢出。
- 临时启动的前端、Java 和 AI 服务均已停止。

## 使用方法

启动三个服务后，打开前端，点击左侧“系统设置”。选择提供商，填写新的 API Key 和准确的模型名称，点击“保存并启用”。随后可在“创建课堂”或“协同讨论”中选择该模型。

如果希望重启后继续使用，应在 `platform/.env` 中配置对应提供商变量并重启 AI 服务；不要把真实密钥提交到版本库。
