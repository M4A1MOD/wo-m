# Demo 0.5 功能矩阵

本版将原始 Demo 0.4 之后的累计更新归档为 Demo 0.5。核对日期：2026-09-21；依据：当前源码及启动配置。下表中的“可验收能力”表示已有实现入口，不代表已完成所有浏览器、模型和 Office 版本的实机验收；验证范围见 [Demo 0.5 验收记录](Demo0.5验收记录.md)。

| 子系统 | Demo 0.5 可验收能力 | 无外部服务时的行为 |
|---|---|---|
| 课程工作区与导航 | 创建课堂、教学工作台同级；进入课程后展开课程准备、课堂教学、课后复盘；工作台与设置始终保留，可切换课程；主要内容与表单样式调整 | 已有课程可使用浏览器本地缓存；数据库同步需要业务后端 |
| 智能课堂生成 | 输入主题、学科、年级、时长；新增选填课程描述，最长 4000 字符；最多 5 份参考资料参与生成；真实模型接收课程描述和资料文字，返回结构化课程与场景 | 默认允许演示模式；演示内容不能等同于真实模型按资料生成的结果 |
| 课程资料解析 | TXT/MD UTF-8 文本读取、PDF 文字提取、PPTX 幻灯片文字提取；清洗、切分统计、摘要与截断标记；单份解析文件不超过 5 MB，返回前 8000 字符 | 解析不需要云端模型，但需要 FastAPI；扫描 PDF、纯图片不具备 OCR 能力 |
| 知识关系图 | 根据当前课程生成结构化节点与关系；最多 4 层，节点短语不超过 15 字符；挂载课程来源标记；节点增删改、关系增删、缩放、类型筛选、重新布局、JSON/SVG 导出 | 可按课程结构生成规则图；真实语义关系需要已配置模型；不等同于向量检索知识库 |
| 思维导图 | 嵌套 JSON 根节点与子节点；最多 4 级，标签不超过 15 字符；保留原课程、目标、知识点、场景、课件、测验来源；节点增删改、分支展开收起、整体展开收起、JSON/SVG 导出 | 可生成课程结构演示导图，保留来源；真实模型生成结果经过结构校验与规范化 |
| 沉浸文本与互动教材 | 展示当前场景内容；“边读边想”提交学习者回答并获取 AI 反馈；教材支持章节阅读、笔记、收藏、完成标记与进度 | 阅读、笔记和完成标记可本地使用；“边读边想”必须连接真实模型 |
| 分段测验 | 单选、多选、简答；客观题按答案判分，简答题交给真实模型按参考答案与评价标准反馈；记录测验尝试 | 客观题判分不依赖外部模型，但接口需要后端与 AI 服务；简答题不以演示结果冒充 AI 批改 |
| 多智能体课堂 | AI 教师、AI 同学、项目教练、记录员可启停；按角色逐轮请求，支持 1～3 轮及停止；携带当前场景、问题和最近 12 条发言；保存对话、笔记与文字板书 | 协同讨论已停用模板，需要 Ollama 或云端真实模型；普通问答仍保留明确标记的演示回复 |
| AI 绘图白板 | 自由曲线、直线、箭头、矩形、椭圆、文字、公式文本；颜色、粗细、网格、撤销重做、元素擦除；根据 AI 板书进行图解排版；随课程保存及 SVG/PNG 导出 | 手动绘制无需模型；图解排版使用已有板书并在前端生成图形，不是模型直接输出自由绘画指令；公式为文本显示 |
| 幻灯片与配图 | 根据当前课程生成课件；火山引擎教学图片生成与资源落盘；按页设置出现、淡入、飞入动画，以及淡化、推进、擦除转场；PPTX 支持可编辑文本、嵌入配图和动画结构 | 文本课件及导出可用；新图片需要图片服务配置与网络；已有图片嵌入仍要求图片资源可访问 |
| 项目式学习 | 小组与成员维护；阶段任务、截止日期、状态；阶段成果上传、下载、删除与说明/反馈；量规指标、权重、人工评分及加权得分；进度随课程保存 | 分组、阶段与量规编辑不依赖模型；上传下载需要业务后端；尚无成员账号协作与按小组独立评分 |
| 课程资源库 | 保存课程相关文件、标题、备注及网课/参考链接；支持原文件下载、删除；无法解析但成功上传的资料显示“仅存档” | 链接与条目可本地保存；文件需要后端落盘；课程资料前端限制 5 MB，项目成果上传限制 20 MB；不承诺自动抓取网课内容 |
| 学习记录与分析 | 初始学习记录为空；按真实操作记录浏览、测验、讨论、反馈；测验均分、知识点掌握度基于作答记录；无成绩时保持未测状态；薄弱点驱动规则学习路径 | 浏览器保存学习记录，课程保存测验与反馈数据；行为时长含固定估值与会话计时，不代表精确有效学习时间；尚无多人班级汇总 |
| 角色朗读与语音输入 | 原“双 AI 音频”明确为“角色对话朗读”；按当前场景拆分角色轮次；浏览器 TTS 支持师生声线、语言与语速；ASR 识别后填入输入框，由用户确认发送 | 依赖浏览器/系统声线及麦克风权限；部分识别实现依赖网络；不支持时提示改用文本；未接入多家云端 TTS/ASR |
| 模型设置与隐私 | DeepSeek、通义千问、Kimi、MiniMax、Ollama 统一接入；API Key、模型与 URL 可编辑；密钥输入不设应用层长度上限；本机用户目录持久保存，重启读取；图片接口独立配置 | 首次使用者需自行配置；Git 不分发本机密钥；本地配置目前为明文 JSON，非加密凭据库 |
| Ollama 接入 | 通过 OpenAI 兼容接口调用；支持读取已安装模型列表；默认地址 `http://127.0.0.1:11434/v1`；使用 `ollama` 占位 Key | 不自动安装、启动 Ollama 或下载模型；默认模型为空且允许演示时回退演示模式；已指定模型但服务离线时明确报错 |
| 导出与分享 | HTML、JSON、PPTX、ZIP；导出当前课程内容；ZIP 增加讨论、项目进度、绘图白板及幻灯片资源描述 | HTML 具备翻页、标签切换等本地交互；图片和附件地址可能依赖原服务；ZIP 当前保存数据和引用，不是完整附件离线备份 |
| Windows 启动与交付 | 根目录一键启动/停止；检查 Node.js、Python、JDK；准备虚拟环境和前端依赖，缺少 Maven 时下载；三个服务健康检查；过滤发布缓存和个人配置 | 首次准备需联网且预装 Node.js 20+、Python 3.11+、JDK 17+；尚未提供免运行环境的 Windows 安装包 |

## 课堂 ZIP 文件清单

| 文件 | 内容 |
|---|---|
| `lesson.html` | 当前课程的交互式课件页面 |
| `lesson.json` | 当前课程及扩展内容数据 |
| `learning-report.json` | 学习行为记录与图谱掌握度数据 |
| `discussion.json` | 对话、笔记及文字板书 |
| `project-progress.json` | 项目分组、阶段提交记录及评价量规 |
| `drawing-whiteboard.json` | 可继续用于编辑的绘图元素数据 |
| `slide-assets.json` | 幻灯片图片引用、提示词、动画及转场设置 |
| `teacher-notes.txt` | 保存的文字板书 |
| `README.txt` | 课堂包说明 |

ZIP 不自动包含上传资料、项目成果文件、图片二进制或 PPTX 文件，也尚无完整课堂包导入恢复流程。HTML/ZIP 的掌握度使用图谱字段，和分析页面按全部作答计算均值的口径存在差异。PPTX 独立导出时会读取配图并嵌入 `ppt/media`；实际打开及放映兼容性需使用目标 Office/WPS 版本验证。

## 与完整项目要求的差距

- 多提供商云端 TTS/ASR、语音文件生成与语音流式课堂尚未完成。
- 通用 3D 可视化、可验证的学科过程仿真与知识小游戏尚未完成。
- 白板尚未提供 LaTeX 数学排版、函数自动绘图及模型驱动的实时画笔序列。
- 项目流程已有基础操作，但成员账号、多人同步、分组提交关联和分组量规评价仍待完善。
- 学情分析仍需改进有效时长、历史数据清理、多用户统计及页面/导出报告口径一致性。
- 资料解析尚无 OCR 与完整向量检索 RAG；图谱展开收起能力不与树形思维导图等同。
- ZIP 附件打包、导入恢复，以及新版独立 HTML 应用/免环境便携包仍待完成。
- 应用界面、构建元数据和部分导出仍标记 0.4；当前文档将累计功能定义为 0.5，程序版本标识统一工作另列待办。
