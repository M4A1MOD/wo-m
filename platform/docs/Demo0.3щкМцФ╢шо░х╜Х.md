## Demo 0.2 与 0.3 整合结果

- 保留 Demo 0.2：课程创建、列表、打开、删除、后端 H2 持久化、localStorage 降级和刷新恢复。
- 纳入 Demo 0.3：9 学科差异化生成、完整课堂结构、动态测验、AI 教师上下文问答、审核发布、HTML/JSON 导出。
- 统一数据入口：后端课程基础数据与浏览器完整课堂内容合并，避免服务端同步后丢失场景详情。
- 统一演示入口：`outputs/智能互动教学平台-demo0.3.html` 与工程前端来自同一构建，不再存在功能不一致的两套 0.3 页面。

## 推荐演示主题

1. 语文：唐诗中的月亮意象——检查文本细读、语言品味和证据表达。
2. 数学：二次函数的图像与性质——检查参数实验、数形结合和分层应用。
3. 英语：Travel Plans——检查听说输入、对话搭建和角色任务。
4. 历史：丝绸之路——检查时间轴、地图、史料与历史解释。
5. 地理：季风气候——检查地图数据、要素联系和区域决策。

## 已知边界

Demo 0.3 的前端学科内容引擎与 AI 服务 mock 可稳定生成结构化课堂。真实大模型密钥和模型提供商仍需按部署环境配置；语音、白板与真实多媒体素材生成不在本次更新范围内，不应表述为已完成。
