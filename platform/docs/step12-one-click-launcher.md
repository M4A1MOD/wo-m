# 第12步：Windows 一键启动与停止

## 使用方法

在 `platform` 目录中双击 `一键启动.cmd`。启动器会完成以下操作：

1. 检查项目内 Python 虚拟环境、D 盘 Maven、Java 17 和 npm 是否可用。
2. 检查 5173、8000、8080 三个端口，避免与其他程序冲突。
3. 在后台启动 FastAPI、Spring Boot 和 Vue 开发服务器。
4. 将输出写入 `platform/.runtime`，避免占用三个命令窗口。
5. 等待三个健康检查全部成功，再自动打开浏览器。

使用结束后双击 `一键停止.cmd`。停止器读取本次启动记录，同时只补充识别命令行中包含当前项目路径的端口进程，避免误停其他项目。

## 异常处理

- 启动失败时窗口不会立即关闭，可按提示查看 `.runtime` 中对应的日志。
- 若项目已经完整运行，再次双击启动文件只会打开浏览器，不会重复启动服务。
- 若只有部分端口被占用，启动器不会猜测进程归属，也不会强制结束它们。
- AI 服务、后端或前端提前退出时，启动器会清理本次已经启动的其他服务。

## 验证结果

- Windows PowerShell 5 兼容语法检查通过，底层脚本使用 ASCII 提示避免旧版 PowerShell 的 UTF-8 无 BOM 解析问题。
- 实际一键启动通过：前端返回 HTTP 200，后端健康状态为 OK，AI 服务健康状态为 UP，并记录三个服务状态。
- 实际一键停止通过：三个端口监听均清除，运行状态文件被删除。
- 全部运行文件、日志和状态均位于 D 盘项目目录，没有安装新软件或向 C 盘写入项目依赖。
