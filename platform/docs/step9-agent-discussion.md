# 第九步：多角色协同讨论

日期：2026-09-20。本轮未安装软件。

## 使用

进入“协同课堂”，选择模型、启用角色、选择 1–3 轮，可输入讨论问题后发送，或直接开始。角色顺序为教师、AI 同学、项目教练、记录员，跳过未启用角色；每个角色每轮发言一次。默认启用教师、同学和记录员。

真实模式每个发言单独调用模型，使用不同角色职责及共享课堂上下文。后一个角色收到前面角色发言；每次携带最近 12 条消息。页面显示当前发言角色以及真实/演示来源。教师返回文字板书，记录员整理笔记，项目教练提出任务和验收建议。

点击停止会中断前端等待并停止安排后续角色，保留已完成发言；供应商已经开始处理的请求可能仍继续并产生费用。中途失败明确提示，保留之前结果，不用模板补齐真实讨论。

## 保存与导出

- 发言、笔记、文字板书、角色开关随课堂内容保存。每条完成发言写入本机；讨论结束、停止或失败时尝试同步服务器。
- 保存失败会提示记录仍在本机，可使用“保存完整课堂”重试。
- 打开不同课程时恢复该课程讨论记录，避免共用一个会话。
- 讨论/答疑期间阻止切换课程、删除课程和生成新课程，避免迟到响应写入其他课堂。
- ZIP 课堂包增加 discussion.json；课堂 JSON 也包含讨论快照。

## 当前边界

这是有限轮次、共享上下文的多角色编排，不是无限自主运行或多用户实时课堂。当前同一轮使用同一个模型提供商，未实现每角色独立模型、工具调用或 WebSocket。记录员在轮次末汇总，不是逐字实时转写。

没有真实供应商密钥，真实角色讨论质量尚待外部模型验收；演示模式明确标记，不代表模型推理。浏览器完整点击流程、TTS 角色声线和真正图形白板仍未验收或实现。
