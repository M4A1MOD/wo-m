# 第八步：三类测验与评分

日期：2026-09-20。未安装新软件。

## 已实现

- 课堂测验支持 single 单选、multiple 多选、short 简答。旧课程未指定题型时按单选处理。
- 新生成演示课程包含三类题型；真实模型的课程生成提示词要求生成三类题目，并携带简答参考答案和评分要点。
- 分段测验和课堂最后一个场景使用统一组件，可切换题目、选择多个选项、填写简答、提交和查看反馈。
- 单选及多选由服务端按标准答案评分：全部正确 100 分，错选或漏选 0 分。无部分分规则。
- 简答使用统一模型层，将学生回答、参考答案和 rubric 发送给所选真实模型，接收 0–100 分和改进建议；演示模式不会伪造简答评分。
- `/api/v1/ai/quizzes/grade` 由 Spring Boot 转发至 AI 服务；异常通过已有错误处理返回。
- 前端阻止空答案及同题重复提交。成绩、答案、反馈、来源、时间写入课程 quizAttempts，并尝试自动保存服务器；保存失败明确提示本机仍保留数据。
- 已答题可回看记录；0 分也计入平均分。HTML 导出能正确显示三类题型的参考答案。

## 验证

- FastAPI 验证单选正确/错误、多选全选对/漏选/错选、重复或越界选项、空简答与 mock 简答拒绝。
- 模拟模型验证简答实际传递学生答案和评分要点，返回合法分数和 live 来源。
- Vue 响应式组件测试验证模板可编译、空答案拦截、重复提交拦截、多选切换、错误时不生成成绩。
- Spring Boot + FastAPI 联调验证批改代理、测验和评分记录保存/读回、未启用真实模型时的明确提示。
- 前端生产构建与后端编译通过；后端原项目仍无单元测试目录。

## 边界

- 当前面向教师演示及自测：题目和标准答案由客户端发送，尚不是防篡改考试系统；没有用户身份隔离或服务端独立答卷表。
- AI 批改为异步请求后的反馈，不是流式输出。真实供应商评分质量仍待配置密钥后验收。
- 旧课堂只有原有题目，不自动把旧单选题变成其他题型；重新生成课堂可获得新题型。
- 浏览器完整操作、多智能体自主讨论与协作仍待后续实现。
