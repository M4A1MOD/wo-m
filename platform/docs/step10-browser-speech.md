# 第10步：浏览器语音授课与语音输入

## 本步范围

完善浏览器 TTS/ASR 的实际交互，去除假识别结果。本步不是云端多语音提供商接入，也不代表全部语音需求完成。未新增依赖、未安装软件、未调用付费服务；构建输出仍位于 D 盘项目目录。

## 使用方法

1. 启动前端，进入“多模态内容”“互动课堂”或“协同课堂”，展开上方“语音设置”。
2. 教师和学生可分别选择浏览器实际提供的声线；默认声线使用所选朗读语言，指定声线使用该声线自身语言。可调节语速。
3. 在“PPT 与旁白”播放当前页，或在“双 AI 音频”逐段播放教师/学生脚本。再次点击播放按钮停止当前旁白；设置栏也提供停止按钮。
4. 点击课堂中的麦克风请求语音识别。结果先填入问题输入框，不自动提交，核对后再发送。
5. 再次点击麦克风取消本次识别并保留原有文字；切换课堂、场景、幻灯片、模块或内容模式，也会取消语音任务。开始答疑/讨论会取消识别。

## 已实现

- 加载真实系统声线，监听声线列表异步更新；教师与学生独立选择声线、语言及语速。
- 旁白开始、结束、取消和失败的状态提示；旧播放的迟到回调不会结束新播放。
- 麦克风识别中展示临时文字，仅最终结果写入输入框；手动修改的文字不被识别结果覆盖。
- 不支持识别、权限拒绝、麦克风缺失、无语音、网络错误、启动失败、超时等情况明确提示。
- 识别最长60秒；主动取消或切换上下文后丢弃迟到结果，组件卸载时清理监听与计时器。
- 播放和识别互斥，避免应用自身旁白被同时录入。
- 云端 `/api/v1/speech/tts` 和 `/api/v1/speech/asr` 尚未接入，现在返回503说明原因，不再返回伪造成功或预设转写文字。
- UI 明确说明旁白与聚光灯未实现时间轴同步，不再宣传已具备音频文件生成/导出能力。

## 验证结果

- 前端 `npm run build` 通过（类型检查与生产构建）。隔离环境阻止构建工具子进程后，获准在隔离限制外完成构建。
- 使用实际 `useSpeech.ts`、Vue 响应式对象和模拟浏览器接口执行检查：不支持API、声线/语速选择、播放迟到回调、重复点击取消、切换课堂、临时/最终识别、保护手动输入、拒绝权限、讨论期间禁用、超时及卸载清理均通过。
- 主界面 Vue 模板编译通过。
- FastAPI TestClient 检查两个云端语音入口均返回503，不返回伪造 transcript。
- 未使用真实麦克风、扬声器或外部语音服务验证音质和准确率；本步未修改 Java 转发层，也未重新执行 Java 服务联调。

## 尚未完成与下一步

- 多云端提供商统一接入、服务端音频合成与真实音频上传识别。
- 音频文件保存/下载及课堂包音频附件。
- 多智能体自动连续语音授课、流式语音、时间轴与幻灯片同步。
- 声线设置目前为本次页面会话配置，不随课堂保存。

浏览器识别的可用性取决于浏览器、权限、网络及其语音服务，不保证离线可用；音频可能由浏览器厂商远程处理。UI 在启动前说明此点。建议在 localhost 或 HTTPS 页面人工验收麦克风权限、播放、取消和中英文输入。
