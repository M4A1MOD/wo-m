# Demo 0.5 验收记录

## 核心流程

1. 双击项目根目录 `一键启动.cmd`，首次准备依赖后启动 Vue、Spring Boot 与 FastAPI；进入系统设置配置真实模型或使用演示模式。
2. 进入“创建课堂”，填写主题、学科、年级、时长，可选填课程描述并上传参考资料；核对生成大纲、目标、场景和测验与课程要求是否一致。
3. 在“教学工作台”选择课程并进入工作区；核对侧栏展开该课程的准备、教学、复盘功能，再回工作台切换课程，确认内容随课程变化。
4. 在“知识与资料”解析参考材料，生成知识关系图；在“教学内容 → 思维导图”生成嵌套导图，检查最多 4 级、节点 15 字符以内、来源标记、增删改、展开收起和 JSON/SVG 导出。
5. 在“课程资源库”上传资料并保存网课链接；下载原文件，刷新后确认条目仍在；不支持解析的已保存文件显示“仅存档”。
6. 在“教学内容”阅读当前场景，提交“边读边想”获得真实 AI 反馈；在互动教材保存笔记、收藏章节和标记完成，检查进度随操作变化。
7. 完成单选、多选和简答测验；进入学习分析检查真实成绩、未测知识点与数据来源；没有测验时不应出现预设均分。
8. 配置图片生成接口，手动生成场景配图；在“PPT 与旁白”设置动画和转场，导出 PPTX 后使用目标 Office/WPS 打开、编辑文字并放映检查。
9. 在“互动课堂”完成问答，绘制曲线、图形和公式文本；使用图解排版、撤销重做及 SVG/PNG 导出；保存课程后重新打开核对绘图内容。
10. 在“协同讨论”选择真实模型，启用角色并运行 1～3 轮讨论；追问已有观点，核对上下文关联、记录员笔记和停止后已完成发言保留。
11. 在“项目式学习”建立小组和成员，设置阶段与日期，上传成果、填写反馈、调整评价权重和评分，保存并核对项目进度与加权得分。
12. 导出 HTML、JSON、PPTX、ZIP；对照功能矩阵核对文件清单和数据内容；最后停止服务并再次启动，检查课程及本机配置持久化。

## 服务边界

- Spring Boot 是前端业务 API 入口，管理课程、原文件资源与 AI 请求代理；课程使用 H2 文件数据库，课程内容另有浏览器本地缓存。
- FastAPI 提供模型配置、课程生成、问答、讨论、测验批改、资料解析、思维导图、知识关系图和图片生成接口。
- TTS/ASR 的实际使用入口是浏览器语音能力，不能以服务中存在同名接口或示例字段认定云端语音已接通。
- 无密钥且未指定可用模型时，默认允许演示模式；课程、导图和普通问答可使用明确标识的演示内容。协同讨论、边读边想、简答题 AI 批改需要真实模型。
- 已配置真实模型但连接失败时应显示错误，不以模板内容冒充成功；图片生成需单独配置，只有手动触发才会请求生成服务。
- Ollama 不属于平台自动安装的依赖。平台不负责启动 Ollama 或拉取模型；未安装时仍可启动并使用非 AI 功能、演示模式或配置云端模型。
- 资源上传接口允许不超过 20 MB 的白名单文件，课程资料入口额外限制为 5 MB；可解析格式为 TXT、MD、PDF、PPTX，原文件存档与内容解析是两个步骤。
- 白板公式以文本绘制，图解排版根据已有 AI 文字板书生成规则图形；项目评分由用户填写，尚非 AI 自动评价或小组独立评价系统。

## 独立版

当前 0.5 交付入口是项目源码与 Windows 一键启动脚本。下载者需要预装 Node.js 20+、Python 3.11+、JDK 17+，首次运行联网准备依赖；不要求安装 Ollama。

`npm run build` 和 `npm run build:demo` 当前均执行前端构建，产物为 `frontend/dist`；没有额外生成内联资源的单文件应用。因此不将历史 `outputs/智能互动教学平台-demo0.4.html` 视为本版已更新的独立入口，也不声明已生成 `demo0.5.html`。

课堂导出的 HTML 是课程内容页面，可进行本地翻页等操作，不等同于完整教学平台。HTML 和 ZIP 中的图片/附件地址可能依赖后端，尚不能保证跨电脑完整离线使用。
