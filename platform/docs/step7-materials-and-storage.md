# 第七步：资料生成与课堂持久化

日期：2026-09-20。未新增依赖或安装软件。

## 使用流程

1. 在课堂生成页上传 TXT、MD、PDF、PPTX。知识库页也可上传，再点击“用已解析资料生成课堂”。
2. 选择已配置的真实模型生成课堂。提取文本通过 Spring Boot 转发到 AI 服务，再随生成请求发送给所选模型；演示模式只保存资料，不做语义生成。
3. 新生成课堂自动提交完整课程内容。后续修改场景、图谱或资料后，点击页眉“保存完整课堂”。
4. 重新加载页面时，优先还原服务器保存的完整内容，旧课程没有内容快照时才使用原有模板补齐逻辑。

## 实现范围

- 每份文件最多 5 MB，每次生成最多 5 份资料；提取文本超过 8000 字符时明确标注截取，生成使用前 8000 字符。
- 文本文件需 UTF-8；PDF 仅支持文字提取，不含 OCR；PPTX 提取幻灯片文本，不解析图片、图表和备注，旧版 PPT 不支持。
- PDF/PPTX 最多 100 页/张；PPTX 读取 XML 总大小有限制，不解压到磁盘。
- 资料解析返回真实文本、分块数量、摘要及截取状态，不再返回虚构的解析质量分数。
- 后端课程增加完整内容 JSON 存储，包含场景、测验、课件结构、图谱、资料正文等。课程元数据仍由原接口管理；发布操作不会清除内容。
- 原始上传文件未保存，存储的是提取文字与元数据。本轮不是向量检索系统，也没有实现原文件下载或扫描件 OCR。
- 聊天消息和全局学习时间线仍未完成独立的服务端持久化；“完整课堂”指课程内容快照，不代表所有会话数据。

## 验证

- 前后端构建通过。
- TXT/MD、实际文字 PDF、PPTX 文字提取通过；空文件、无效格式、非 UTF-8 文本、旧 PPT 被拒绝；超长文字明确截取。
- 使用前端真实函数 → Spring Boot → FastAPI → 本地模型模拟服务器验证资料正文实际送达模型请求，课程内容保存成功。
- 模拟清空本地存储后重新初始化前端，教师修改后的场景及上传文字恢复成功。
- 后端使用 D 盘独立 H2 文件数据库重启后，课程内容及资料正文仍可读取；已删除测试课程，保留测试数据库文件供排查。
- 无真实模型密钥，因此基于资料的语义生成质量未进行外部供应商实测；本轮也未做完整浏览器操作验收。
