# Demo 0.4 验收记录

## 核心流程

1. Demo 0.3 课程自动迁移至 `zhixue-courses-demo04`，并补全图谱、多模态资产和学习路径。
2. 九个学科均可生成五场景课堂，生成后进入知识库与图谱页面。
3. 资料上传、图谱筛选/缩放/编辑、多模态六种形态、多智能体讨论、白板、测验和学情分析均有可操作交互。
4. 课堂浏览、测验、讨论、答疑、语音和导出会写入学习记录。
5. HTML、JSON、PPTX、ZIP 四类导出由浏览器本地完成。

## 服务边界

- Spring Boot 继续作为前端唯一业务 API 入口。
- FastAPI 提供 Provider、资料解析、图谱生成、多模态内容、TTS、ASR 和学习报告接口。
- Provider 未配置密钥时返回稳定演示结果，前端功能不被阻塞。

## 独立版

`outputs/智能互动教学平台-demo0.4.html` 由正式 Vue 构建产物内联生成，无外部静态资源依赖，可直接双击离线演示。
