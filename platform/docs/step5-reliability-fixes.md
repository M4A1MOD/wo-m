# 第五步：联调问题修复

日期：2026-09-20。本轮未安装新软件；构建和测试使用已有工具及 D 盘项目内缓存。

## 完成内容

- AI 服务按用户指定时长分配场景分钟数，整数时长总和与课程时长一致；前端本地降级模板也按同样规则分配。
- 知识图谱按实际知识点生成节点及关系，保留超出原来固定数量的知识点，去除重复/空白知识点，不再生成悬空边。
- 后端对课程时长 20–120 分钟及文本长度进行校验；支持 `contentStyle` 和兼容字段 `content_style`，前端统一发送 `contentStyle`。
- AI 服务上游 400/422 转换为业务端 400，其他上游 HTTP 错误转换为 502，连接失败转换为 503，返回明确错误码及提示。
- 发布/退回草稿通过 PUT 保存服务器课程状态；请求失败时保持原状态并显示失败提示，防止重复提交。
- 生成后的提示明确标注模板模式；答疑请求失败时清除 AI 在线状态并告知使用本地模板。

## 验证

- Vue 类型检查与 Vite 生产构建通过。
- Maven 编译通过；后端仍无已有单元测试用例，未将 Maven 成功视为功能验收。
- FastAPI TestClient 检查 20–120 分钟共 101 个输入；场景均为正整数，总和准确。
- 图谱检查 0、1、2、3、4、8、20 个知识点，所有知识点保留且所有边引用存在的节点。
- Node 中执行前端 TypeScript 转译代码：9 学科 × 101 时长，共 909 个本地分配检查通过。
- 在模拟 Vue ref/computed 和 fetch 的环境中执行真实 publish 函数：成功时发送 PUT 并更新状态；失败时状态不变且显示失败消息。此检查不代替浏览器操作验收。
- 启动临时内存数据库后端及 AI 服务：非法时长返回 400；AI 未启动返回 503；两种内容风格字段请求均成功；场景时长与图谱检查通过；超长聊天历史引发上游 422 后对外返回 400。
- 课程发布/退回草稿后从服务器重新读取状态均正确。测试课程已删除，临时服务在测试后停止。
