# 开发约定

## API 前缀

- 业务后端对前端：`/api/v1`
- AI 服务对业务后端：`/api/v1`

## 统一响应

业务后端返回：

```json
{
  "code": "OK",
  "message": "success",
  "data": {}
}
```

## 核心状态

课程状态：`DRAFT`、`GENERATING`、`PENDING_REVIEW`、`PUBLISHED`、`COMPLETED`、`FAILED`。

审核状态：`NOT_SUBMITTED`、`PENDING`、`APPROVED`、`REJECTED`。

## 首批接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/auth/login` | 登录 |
| GET | `/courses` | 课程列表 |
| POST | `/courses` | 创建课程草稿 |
| GET | `/courses/{id}` | 课程详情 |
| PUT | `/courses/{id}` | 修改课程 |
| DELETE | `/courses/{id}` | 删除课程 |
| POST | `/courses/{id}/generate` | 请求生成课堂 |
| POST | `/courses/{id}/review` | 提交或处理审核 |
| GET | `/courses/{id}/scenes` | 查询课堂场景 |
| POST | `/questions/{id}/answers` | 提交答案 |
| POST | `/courses/{id}/chat` | AI 教师问答 |
| POST | `/courses/{id}/materials` | 上传课程资料 |

## 分支和版本

每个 Demo 版本保留可运行标签或压缩备份。P0 功能完成前不引入 3D、复杂图谱和多人实时课堂等高风险能力。
